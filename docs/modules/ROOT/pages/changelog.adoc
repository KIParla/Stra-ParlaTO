== v1.1.0 (2026-10-15)

=== What's changed in 1.1.0

* EAF: new layered structure. Each speaker has the tiers `ref@<speaker>` (time-aligned transcription units, value = `tu_id`) and `tx@<speaker>` (enriched transcription, the only text read back), and `ft@<speaker>` (free translation). The derived word-level tiers are no longer in the files (they are generated on request). The files are valid against the official EAFv3.0 schema.
* Stable ids: unit and token ids no longer change when an `.eaf` is edited and synchronized back to the `tsv/` file. Annotations that the `.eaf` cannot carry (lemma, POS, `Language=` labels) are kept.
* Unidentified speakers: placeholders made only of question marks (`??`, `???`, ...) in order of first appearance in each conversation, each with a row in `metadata/participants.tsv`; empty `form` values are written as `_`.
* Translations: the translation tier names are corrected; a translation of an untranscribed unit is tracked in an issue.
* Corrected unit texts: stray symbols attached to the neighbouring word, glued words and punctuation inside words fixed.
* Automatic validation of the tables against the CSVW schema on every push.

== v1.0.0 (2026-10-11)

=== First release of Stra-ParlaTO

Stra-ParlaTO collects conversations and semi-structured interviews recorded in Turin and its province, involving speakers of Italian as a foreign or second language. It was compiled within the "DiverSIta – Diversity in spoken Italian" project (PNRR, NextGenerationEU; PI: Caterina Mauri).

* 82 conversations with 139 speakers, anonymized; collection year 2025
* Conversation metadata include the `community` of the speakers (moroccan, romanian, peruvian)
* Some conversations have a `_trad` tier with an Italian translation of the tokens produced in the speakers' other languages
* Time-aligned ELAN files, verticalized `tsv/` files (20 columns, including the `code_variation` features), linearized `linear-enriched/` and `linear-orthographic/` texts, and CSVW metadata (`csv-metadata.json`)
